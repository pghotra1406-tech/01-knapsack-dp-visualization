
# 01-knapsack-dp-visualization

0/1 Knapsack Dynamic Programming with ASCII Table Visualization.

## Objective
To find the maximum total value of items that can fit inside a bag with a given capacity using the 0/1 Knapsack Dynamic Programming algorithm.

## Algorithm
1. Read the number of items and bag capacity.
2. Read the weight and value of each item.
3. Create a dynamic programming table.
4. Process items one by one.
5. Calculate the maximum value by taking or not taking each item.
6. Display the DP table step by step in ASCII format.
7. Save the results in result.txt.

## Time Complexity
O(n * W)

## Space Complexity
O(n * W)

## Project Files
- knapsack.py: Python program
- input.txt: Test case inputs
- result.txt: Final results
- README.md: Project documentation
